# README 普通用户优先改写设计

## 目标

让第一次接触 OmniMe 的普通 macOS 用户快速理解产品价值、完成安装、确认记录状态，并知道数据与隐私边界。README 只描述当前工作区代码已经实现且用户能够使用的能力。

## 核心叙事

OmniMe 是一个本地优先的 macOS 输入活动记录与复盘工具。当前捕获模型以 Enter 提交为边界，记录用户实际提交的文本，而不是保存连续的原始按键流。系统会优先使用可信输入框内容，并在文本不可读时按配置仅记录字符数；非文本输入控件上的 Enter 会被跳过。

## 信息架构

README 按普通用户的实际使用顺序组织：

1. 产品简介与适用场景。
2. 当前核心能力。
3. 快速安装、辅助功能权限与首次启动。
4. 菜单栏、Web、报告、导出和 Obsidian 等常用方式。
5. 提交捕获规则与可能跳过记录的原因。
6. 本地数据、隐私模式、忽略应用和可选 AI 的边界。
7. 常用配置、健康检查与故障排查。
8. 精简的开发验证与相关文档链接。

## 内容取舍

保留并更新：安装方式、权限、菜单栏、Web、CLI、AI 后端、数据路径和隐私说明。

新增：Enter 提交捕获模型、可信输入保护、不可读输入仅计数、提交上下文、捕获诊断、业务日时区、Obsidian 命令与健康检查。

删除或压缩：虚构报告示例、内部 SQL 表结构、过时模块树、旧版本更新日志和面向实现者的冗长细节。

## 准确性约束

- Web 默认地址使用代码中的 `http://127.0.0.1:8001`。
- 命令和参数以 `src/ominime/main.py` 为准。
- 配置键以 `src/ominime/config.py` 为准。
- 捕获行为以监听器、提交处理器与测试覆盖的行为为准。
- 不声称能够捕获所有应用中的每一次输入；明确辅助功能限制和可信捕获策略。
- 不再提及鼠须管或 Rime。
