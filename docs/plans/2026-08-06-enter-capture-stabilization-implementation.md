# Enter 捕获稳定化实施计划

> 对应设计：`docs/plans/2026-08-06-enter-capture-stabilization-design.md`

## 任务 1：事件回调卸载与提交尝试去重

- 在 `keyboard_listener.py` 定义不可变原始键盘事件。
- 监听启动时创建工作队列和线程，停止时有序排空并退出。
- EventTap 回调只采样并投递；未启动监听器时保留同步处理，方便单元测试与直接调用。
- keyDown 完成 Enter 尝试后抑制对应 keyUp；为换行修饰键增加明确跳过行为。
- 先补失败测试，再实现。

## 任务 2：可信候选与隐私门禁

- 在 `context_capture.py` 增加安全输入识别和字段身份生成。
- 在 Enter 管线统一验证焦点状态、受保护属性、文本尺寸和来源。
- 区分 `degraded_context` 与 `focused_element_not_text_input`。
- 移除通用剪贴板兜底调用，保留实现代码只供未来显式适配器复用。
- 先补安全输入、超大值、降级状态和剪贴板不可达测试。

## 任务 3：字段级缓存

- 最近 AX 快照携带字段身份。
- 焦点字段变化时清理该应用旧字段的文本与计数缓存。
- Enter 只接受当前字段的缓存。
- 补两个输入框间切换的回归测试。

## 任务 4：统计与跨进程状态

- 菜单栏只在成功保存后增加实际字符数。
- 在 `runtime_state.py` 写入原子共享状态文件，读取时校验心跳期限。
- 监听健康检查刷新心跳。
- 内置 Web 服务启动前探测现有健康服务。
- 补菜单计数、跨进程读取、过期状态和端口复用测试。

## 任务 5：验证与交付

- 运行捕获、菜单栏、运行状态和 Web 健康聚焦测试。
- 运行完整测试套件与项目现有静态检查。
- 检查 diff，只保留本轮文件；不代提交工作区中已有的无关改动。
- 复核 EventTap 热路径中不存在 AX、剪贴板或 sleep。
